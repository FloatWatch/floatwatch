지난 발표에서는 / 프로젝트의 기획 배경과 / 1차 모델 학습, / 그리고 MVP 구조를 소개했습니다. /
이번 발표에서는 / 기존 내용을 반복하기보다, / 지난 발표 이후 새롭게 구현하거나 / 수정한 부분을 중심으로 말씀드리겠습니다. /

둘째, / 업로드 분석뿐 아니라 / 실시간 탐지 기능을 추가했습니다. /
셋째, / 추가 학습 결과와 혼동 행렬을 / 여러 관점에서 비교할 수 있도록 / AI 리포트를 확장했습니다. /

## 슬라이드 4 · 프로젝트 일정

먼저 / 프로젝트 일정에서 / 이번 주까지의 진행 상황을 말씀드리겠습니다. /

1주차와 2주차에는 / 프로젝트 기획, / 데이터셋 수집, / 서비스 MVP 구축과 / 1차 모델 학습을 진행했습니다. /

3주차에는 / 기존의 단일 모델 분석 구조를 / 4개 모델 통합 분석 구조로 개편했습니다. /
관리자가 / YOLOv8s, / YOLO11s, / YOLO26s, / RT-DETR 계열별로 / 대표 PT를 지정할 수 있도록 했고, /
하나의 미디어를 등록하면 / 등록된 대표 모델들이 / 한 번에 분석되도록 구현했습니다. /

현재 / 3주차까지의 작업은 완료했으며, /
4주차에는 / 동일한 조건에서 모델별 취약 구간과 오류 사례를 검증하고, /
5주차에는 / 전체 기능과 예외 상황을 통합 테스트한 뒤 / 최종 모델과 발표 시나리오를 정리할 계획입니다. /

## 슬라이드 7 · 시스템 아키텍처 변경

다음은 / 변경된 시스템 아키텍처입니다. /

전체적인 / 프론트엔드, / 백엔드 API, / AI 추론, / 데이터 저장 구조는 유지했습니다. /
다만 / 분석 처리 단위가 / 하나의 선택 모델에서 / 4개 대표 모델의 분석 묶음으로 변경됐습니다. /

프론트엔드에서는 / 대표 PT와 미디어를 준비하고, /
백엔드에서는 / 사용자 인증과 분석 자산을 검증한 뒤 / 분석 묶음을 생성합니다. /
AI 엔진은 / 등록된 대표 모델을 순차적으로 추론하고 / 모델별 바운딩 박스 결과를 생성합니다. /
마지막으로 / 모델별 결과와 비교 지표를 / 하나의 분석 기록으로 저장합니다. /

대표 PT가 등록되지 않은 모델은 / 전체 분석을 중단시키지 않고 제외하며, /
등록된 모델의 결과만으로도 / 비교 분석을 계속할 수 있도록 구성했습니다. /

즉, / 기존의 업로드, 검증, 추론, 기록 흐름은 유지하면서 / 그 안의 분석 단위를 / 4개 모델 비교 구조로 확장했습니다. /

## 슬라이드 8 · 기능 소개

이번 주 기능은 / 크게 두 가지 흐름으로 나누어 설명할 수 있습니다. /
첫 번째는 / 업로드 기반 분석이고, / 두 번째는 / 실시간 탐지입니다. /

먼저 / 업로드 기반 분석입니다. /
사용자는 / 네 개의 모델 계열마다 / 분석에 사용할 대표 PT를 지정하고, / 이미지나 동영상을 등록합니다. /
분석을 시작하면 / 동일한 미디어를 / 등록된 대표 모델들이 한 번에 분석합니다. /

분석이 완료되면 / 모델 탭을 눌러 / 각 모델의 바운딩 박스를 확인할 수 있고, /
클래스별 탐지 수와 평균 신뢰도, / 전체 탐지 수와 처리 속도를 / 그래프로 비교할 수 있습니다. /
이 결과는 / 하나의 분석 묶음으로 저장되기 때문에 / 탐색 기록에서 다시 조회할 수 있습니다. /

두 번째는 / 이번 주에 새로 추가한 실시간 탐지 기능입니다. /
현재는 / 기능 검증을 위해 테스트 카메라를 연결해 동작시키고 있으며, /
최종적으로는 / 연안 CCTV 영상 스트림과 / 관측 위치 정보를 연계하는 것을 목표로 하고 있습니다. /

실시간 탐지에서는 / 적용할 모델을 선택한 뒤, /
영상 프레임에서 / 클래스, 신뢰도, 바운딩 박스를 즉시 확인할 수 있습니다. /
탐지 시간과 위치, 클래스 이벤트는 / 세션 단위로 기록하고 / 이후 상세 기록에서 다시 조회할 수 있도록 구성했습니다. /

따라서 현재 FloatWatch는 / 업로드한 미디어를 정밀하게 비교하는 방식과 / 현장 영상을 실시간으로 확인하는 방식을 / 함께 제공하는 구조로 확장됐습니다. /

## 슬라이드 10 · AI 리포트 A — YOLOv8s·YOLO11s 2차 학습

AI 리포트 A는 / YOLOv8s와 YOLO11s의 / 2차 학습 결과입니다. /

두 모델은 / 동일한 데이터 분할과 학습 조건에서 비교했습니다. /
입력 크기는 800픽셀, / 배치 크기는 4, / 옵티마이저는 AdamW, / 학습률은 0.001로 설정했습니다. /
최대 150에폭 안에서 / 성능 개선이 멈추면 조기 종료하도록 구성했습니다. /

학습 결과 / YOLOv8s는 / Precision 85.09퍼센트와 / mAP50 84.16퍼센트를 기록해 / 정밀도와 기본 탐지 성능에서 소폭 우세했습니다. /
YOLO11s는 / Recall 80.46퍼센트와 / mAP50-95 69.29퍼센트를 기록해 / 객체를 놓치지 않는 성능과 / 더 엄격한 경계 기준에서 우세했습니다. /

즉, / 두 모델의 전체 성능은 비슷하지만, /
YOLOv8s는 정밀도 측면에서, / YOLO11s는 재현율과 경계 정밀도 측면에서 / 각각 다른 강점을 보였습니다. /

각 모델의 버튼은 / 서로 독립적으로 동작합니다. /
평가 그래프 버튼에서는 / PR 곡선과 F1 곡선을, /
이미지 버튼에서는 / 라벨링 결과와 모델 추론 결과를, /
혼동 행렬 버튼에서는 / 일반 혼동 행렬과 정규화 혼동 행렬을 확인할 수 있습니다. /

[시연 선택] / YOLO11s의 혼동 행렬 버튼을 누르겠습니다. /
가로축은 / 실제 정답 클래스이고, / 세로축은 / 모델이 예측한 클래스입니다. /
대각선은 / 실제 클래스와 예측 클래스가 일치한 경우이며, /
대각선 밖의 값은 / 다른 클래스로 예측된 패턴을 의미합니다. /

다음 학습에서는 / 취약하거나 표본이 적은 클래스의 데이터를 보강하고, /
클래스 균형을 고려해 증강 조건을 조정한 뒤, /
동일한 미디어에서 / 정확도와 처리 속도를 다시 검증할 계획입니다. /

## 슬라이드 11 · AI 리포트 B — YOLO26s·RT-DETR-L 확장 실험

AI 리포트 B는 / YOLO26s와 RT-DETR-L을 대상으로 한 / 확장 모델 실험입니다. /

이 실험에는 / 6배 증강 데이터셋을 적용했고, /
입력 크기 800픽셀, / 배치 크기 4, / AdamW와 학습률 0.001을 사용했습니다. /
또한 / Mosaic과 MixUp 증강을 적용했습니다. /

학습 결과 / RT-DETR-L은 / Precision 88.88퍼센트, / Recall 81.37퍼센트, / mAP50 85.45퍼센트를 기록해 / 분류와 탐지 지표 전반에서 우세했습니다. /
반면 YOLO26s는 / mAP50-95에서 69.50퍼센트를 기록해 / 더 엄격한 IoU 기준의 경계 정밀도에서 우세했습니다. /

다만 / A와 B의 모델은 / 데이터 구성과 학습 조건이 완전히 같은 하나의 실험군이 아니기 때문에, /
수치만으로 네 모델의 절대 순위를 정하기보다는 / 각 실험 안에서의 강점과 / 반복되는 오분류 패턴을 중심으로 해석했습니다. /

다음 단계에서는 / 동일한 미디어 조건에서 4개 모델을 교차 검증하고, /
정확도뿐 아니라 / FPS, 메모리 사용량, 추론 지연을 함께 측정해 / 실제 서비스에 적합한 모델 구성을 판단할 계획입니다. /

## 슬라이드 12 · AI 리포트 C — 인터랙티브 3D 혼동 행렬

AI 리포트 C는 / 네 모델의 혼동 행렬을 / 하나의 공간에서 비교하기 위해 새롭게 구성한 / 인터랙티브 3D 그래프입니다. /

X축은 / 실제 정답 클래스, /
Y축은 / 모델이 예측한 클래스, /
Z축은 / 실제 클래스 표본 중 / 해당 클래스로 예측된 정규화 비율을 의미합니다. /
점의 색상은 / 비교할 모델을 구분합니다. /

대각선 좌표의 점은 / 실제 클래스와 예측 클래스가 같은 경우이고, /
비대각선 좌표의 점은 / 다른 클래스로 예측된 경우입니다. /
점의 높이가 높을수록 / 해당 실제 클래스가 / 해당 예측 클래스로 분류된 비율이 크다는 의미입니다. /

그래프는 / 마우스로 드래그해 시점을 바꿀 수 있고, /
마우스 휠이나 우측 확대 도구로 / 원하는 구간을 확대할 수 있습니다. /
점에 마우스를 올리면 / 실제 클래스, 모델 예측 클래스, / 그리고 해당 비율을 확인할 수 있습니다. /

[시연] / 대각선 점 하나를 가리키겠습니다. /
이 경우에는 / 실제 클래스와 모델 예측 클래스가 같으며, /
표시된 퍼센트는 / 해당 실제 클래스 표본 중 / 같은 클래스로 예측된 비율입니다. /

[시연] / 다음으로 비대각선 점을 가리키겠습니다. /
이 값은 / 해당 실제 클래스 표본 중 / 다른 특정 클래스로 예측된 비율을 의미합니다. /
이와 같이 / 동일 좌표에서 모델별 점의 높이와 색상을 비교하면 / 어떤 클래스 조합에서 / 특정 모델의 혼동이 반복되는지 확인할 수 있습니다. /

그래프에는 / 정규화 혼동 행렬의 대각선 값과 / 10퍼센트 이상의 주요 오분류를 표시했습니다. /
따라서 / 전체 셀을 모두 나열하기보다 / 학습 개선에 필요한 주요 패턴을 집중해서 확인할 수 있습니다. /

## 발표 중 반드시 구분할 표현

- 현재 실시간 탐지는 테스트 카메라로 기능을 검증한 초기 구현이며, 연안 CCTV API·스트림 연계는 향후 계획입니다.
- YOLOv8s와 YOLO11s는 반드시 `2차 학습`으로 표현합니다.
- YOLO26s와 RT-DETR-L은 `6배 증강 데이터셋을 적용한 확장 모델 실험`으로 표현합니다.
- A와 B는 데이터 구성과 학습 조건이 완전히 동일한 단일 실험군이 아니므로 네 모델의 절대 순위를 단정하지 않습니다.
- 혼동 행렬의 가로축은 실제 정답 클래스, 세로축은 모델 예측 클래스입니다.
- 3D 그래프의 Z축은 정확도 자체가 아니라 `실제 클래스 표본 중 특정 클래스로 예측된 정규화 비율`입니다.

## 권장 시연 순서

1. 기능 소개에서 업로드 분석과 실시간 탐지의 두 흐름을 짚습니다.
2. AI 리포트 A에서 평가 그래프 또는 혼동 행렬 버튼 하나만 시연합니다.
3. AI 리포트 B는 수치와 강점만 설명하고 버튼 시연은 생략해 시간을 확보합니다.
4. AI 리포트 C에서 회전 → 확대 → 대각선 점 → 비대각선 점 순으로 시연합니다.
5. 시연 중 그래프를 과도하게 회전하지 말고, 시점 초기화 버튼으로 원래 시점에 복귀한 뒤 다음 슬라이드로 이동합니다.
